DevPulse is a personal analytics platform that aggregates coding activity from multiple sources into a single dashboard.

## Motivation

Keeping track of development progress across GitHub, LeetCode, and personal projects can be fragmented. DevPulse provides a unified view with meaningful metrics instead of scattered statistics.

## Features

- GitHub contribution insights
- Coding streak tracking
- Project timeline visualization
- Weekly productivity reports
- Responsive dashboard optimized for desktop and mobile
