PixelVault is a privacy-focused photo storage application where encryption happens before files leave the user's device.

## Security Model

Images are encrypted using client-generated keys before upload, ensuring the server stores only encrypted content.

## Features

- Client-side encryption
- Album organization
- Secure sharing links
- Image compression
- Responsive gallery interface
