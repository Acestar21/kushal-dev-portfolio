MCP V1 was the foundational project that led to Nexus — a Tauri-based desktop app combining a local Ollama LLM with practical tool access: file operations, browser search, and screenshot capture, all exposed through an early MCP server/client architecture.

## What it explored

This was the first real implementation of the MCP protocol pattern that later became core to Nexus — giving an LLM structured, callable tools instead of just chat.

## Status

Archived after its concepts were carried forward and expanded in Nexus. Kept as a reference for how the architecture evolved.
