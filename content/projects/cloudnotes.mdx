CloudNotes is a markdown-first note-taking application designed for organizing technical documentation.

## Why Markdown

Markdown keeps notes portable and future-proof while remaining easy to edit using any text editor.

## Features

- Markdown editor with live preview
- Full-text search
- Tag-based organization
- Dark mode
- Automatic version history
