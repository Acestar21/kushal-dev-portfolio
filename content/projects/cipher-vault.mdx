CipherVault is a web app for storing sensitive data with client-side AES-256-GCM encryption — the server never sees plaintext, and in this case there isn't even a server: encryption/decryption happens entirely in the browser via the native Web Crypto API.

## Server-blind by design

All encryption and decryption happens client-side. Encrypted blobs are the only thing ever persisted, so even if storage were compromised, the data is useless without the user's key.

## Why AES-256-GCM

GCM (Galois/Counter Mode) provides both encryption and built-in authentication (detects tampering), which matters for a vault where data integrity is as important as confidentiality.
