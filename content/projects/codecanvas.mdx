CodeCanvas is a browser-based playground for experimenting with frontend code and organizing reusable snippets.

## Design Goals

The project focuses on minimizing setup time so developers can prototype ideas immediately without configuring a local environment.

## Features

- Live HTML/CSS/JavaScript preview
- Snippet library
- Theme customization
- Auto-save sessions
- Export projects as ZIP files
