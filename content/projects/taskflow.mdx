TaskFlow is a lightweight project management application focused on real-time collaboration.

## Why WebSockets

Traditional polling introduces unnecessary requests and delayed updates. WebSockets allow every connected client to receive changes instantly, creating a smoother collaborative experience.

## Features

- Drag-and-drop Kanban boards
- Live task updates
- Team workspaces
- Activity history
- Keyboard shortcuts for power users
