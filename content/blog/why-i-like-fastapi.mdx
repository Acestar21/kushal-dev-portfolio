I've experimented with several Python web frameworks, but FastAPI consistently ends up being the one I reach for.

## Type hints everywhere

Python's type annotations aren't just documentation anymore—they're used to generate validation, documentation, and editor support automatically.

## Automatic API Docs

One feature I appreciate is that every endpoint is documented without additional work.

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/hello")
def hello():
    return {"message": "Hello, world!"}
```

Running the application immediately provides interactive API documentation, making testing much easier during development.
