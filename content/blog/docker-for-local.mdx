I originally thought Docker was mainly useful for servers.

After using it locally, I realized it also solves dependency and environment issues during development.

## Reproducible environments

When everyone uses the same container, everyone gets the same versions of databases, runtimes, and tooling.

## Example

```yaml
version: "3.9"

services:
  postgres:
    image: postgres:16
    ports:
      - "5432:5432"
```

It takes a little setup initially, but it usually saves much more time later.
